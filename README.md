# Product Association Rules

Homework 4 project using the [UCI Online Retail dataset](https://archive.ics.uci.edu/dataset/352/online+retail). Each invoice is a basket; the app uses FP-Growth to find frequent product groups and shows association rules with support, confidence, and lift.

**[Open the live demo](https://predprof.github.io/products-association-rules/)**

## Features

- Adjust minimum support and confidence.
- Inspect a rule and compare its reverse direction.
- Run the built-in self-checks.

## Run locally

Open `index.html` in a modern browser. Keep `transactions.js`, `script.js`, and `style.css` in the same directory.
